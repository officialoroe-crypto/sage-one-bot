# Stage-by-Stage Visual Specification

## Shared base layer

Every stage keeps:
- black/dark space surface
- deep-blue SAGE core energy
- electric-blue/white interface highlights
- Mount Everest / moon / Buddha / stars / subtle clouds environment
- stable typography and information hierarchy
- controlled material accents only

Material accents may affect the SAGE Core, particles, edge highlights, badges, achievement effects, and transition energy.

### Intensity contract

**Low**
- subtle particles
- lower glow
- gentle material accents
- stable readability

**Mid**
- more particles
- stronger glow
- clearer material identity
- more visible Core response

**High**
- maximum intended intensity
- rich particles
- strongest controlled glow
- evolution-ready state

The three states are intensity levels, not separate ranks.
