## Asset rules

- Do not redraw or substitute the canonical SAGE logo with a generic S.
- Do not use external stock imagery as a silent replacement for owner-approved reference assets.
- Keep source assets separate from generated material effects.
- Store asset provenance with implementation notes when production assets are added.
- Material effects should be procedural/data-driven where practical.

## Image-reference checklist

For each production visual comparison:
- same overall composition
- same environment hierarchy
- same SAGE identity
- correct stage name/order
- correct material direction
- correct Low/Mid/High intensity
- no full material-color takeover
- readable typography
- correct badge/emblem treatment
- transition begins/ends in the correct states
