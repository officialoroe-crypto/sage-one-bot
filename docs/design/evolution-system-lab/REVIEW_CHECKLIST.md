# Evolution Pixel / Visual Review Checklist

## Structural

- [ ] UI structure is unchanged between Evolutions.
- [ ] SAGE Core remains the primary visual anchor.
- [ ] No evolution-specific screen duplication.
- [ ] Low / Mid / High are state changes, not extra ranks.
- [ ] Stage order matches the locked 13-stage catalog.

## Identity

- [ ] Black/deep-blue SAGE foundation remains visible.
- [ ] Electric blue/white SAGE accents remain present.
- [ ] Evolution material is additive.
- [ ] Canonical SAGE logo is used.
- [ ] Spark remains visually separate from Evolution.

## Environment

- [ ] Mount Everest remains recognizable.
- [ ] Moon remains behind the environment composition.
- [ ] Golden Buddha remains between Everest and moon.
- [ ] White/blue moonlight is preserved.
- [ ] Stars/clouds remain controlled background layers.

## State

- [ ] Low has subtle particles and lower glow.
- [ ] Mid has stronger particles/glow.
- [ ] High is the evolution-ready intensity.
- [ ] Material identity is clear without taking over the UI.

## Transition

- [ ] High state begins the transition.
- [ ] Particle acceleration is visible.
- [ ] Energy concentrates.
- [ ] Environment darkens.
- [ ] Shockwave/burst occurs.
- [ ] Old material breaks apart.
- [ ] New material forms.
- [ ] New particles appear.
- [ ] New rank resolves.
- [ ] Interface settles into next Low.

## Evidence

For every reviewed state, record:
- stage
- intensity
- platform
- screenshot/video reference
- source reference version
- known adaptation
- deviation
- reason for deviation
- reviewer/date

No visual deviation should silently become a new product rule.
