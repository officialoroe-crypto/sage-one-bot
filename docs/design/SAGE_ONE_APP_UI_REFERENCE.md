# SAGE ONE — App UI Reference

Status: OWNER-APPROVED REFERENCE
Source: owner-provided visual reference, 2026-09-22
Role: Mobile application visual/UX reference for SAGE ONE and SAGE WORKFLOW.

## Core visual direction

- Premium cinematic sci-fi interface.
- Near-black/deep-space foundations.
- Thin electric-blue/cyan borders with controlled glow.
- Cyan, blue and violet are the primary intelligence/interaction accents.
- Gold is reserved for SAGE Credits, Spark/economy and premium states.
- Green represents successful/completed states.
- Red/orange represents failure/error states.
- Purple/blue represents recovery/evolution states.
- UI should feel advanced, precise and premium rather than noisy or game-like.
- SAGE's orbital S mark is the central visual identity and may appear as a system/core visualization.

## Main command center principles

- SAGE should feel like a personal AI workspace, not only a chat app.
- Home/command center can surface current focus, active work, shortcuts and system state.
- Quick actions should expose high-value actions such as Research, Create, Execute and Tools.
- Navigation should remain simple enough for one-handed mobile use.
- Persistent bottom navigation can expose core destinations while secondary tools remain contextual.

## SAGE WORKFLOW direction

The app reference should evolve the workflow concept beyond a chat response.

For AI reasoning/execution:
UNDERSTANDING -> RESEARCHING -> ANALYZING -> VERIFYING -> SUCCESS / FAILURE -> RECOVERY

For creative/content work:
IDEA -> PLAN -> CREATE -> ASSETS -> EDIT -> VERIFY -> PUBLISH -> ANALYZE -> IMPROVE

The second workflow is a first-class SAGE WORKFLOW concept and should connect projects, assets, actions, publishing and analytics.

This is a reference language, not a pixel-copy target. Extract the visual hierarchy, atmosphere, information architecture, state language and interaction ideas, then create an original SAGE ONE design system suitable for the actual Flutter application.
