## Unified Evolution rules
- 13 canonical ranks remain the source-of-truth order.
- Low/Mid/High are intensity states, not additional ranks.
- Skill progression and money/Spark progression remain separate.
- Evolution is lifetime achievement and is not reduced by Spark spending/withdrawal.
- SAGE blue/black identity remains persistent; material accents are secondary.
- Transition effects must not silently mutate persisted achievement.

## Completion rule
A phase is not considered fully production-complete merely because a screen exists. Final completion requires:
1. Real API path where applicable.
2. Success and failure handling.
3. Refresh/restart behavior.
4. Regression coverage where practical.
5. Manual/reference visual review for visual claims.
6. Android/device validation for device-specific behavior.
