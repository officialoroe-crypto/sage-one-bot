# OWNER PREFERENCES

## Communication

- Direct and practical.
- Action-oriented.
- Minimal unnecessary fluff.
- Prefer useful detail over vague reassurance.
- Avoid repetitive setup steps when a coherent batch is possible.

## Technical workflow

- Prefer complete file replacements for substantial code changes.
- Give exact Windows paths and commands when local action is required.
- Keep local CPU/resource usage reasonable.
- Use CI/cloud/background execution for heavy workloads where appropriate.

## Creative workflow

- Premium, cinematic, aesthetic direction is preferred when relevant.
- Canonical supplied assets should be preserved exactly unless the owner asks for a variation.
